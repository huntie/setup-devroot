# `npx huntiestack`

Prints the agent prompt that sets up a [devroot](https://github.com/huntie/setup-devroot).

## Usage

```sh
npx huntiestack
```

Paste the output into your agent:

```
Set up my devroot.
Follow https://raw.githubusercontent.com/huntie/setup-devroot/main/INSTALL.md
```

## Requirements

macOS or Linux, and Node.js 18 or later.
